# Checks reference

zero-audit runs 62 checks on every audit. Each check has a numeric id, a severity, a theme and a scope:

- **Severity**: `error`, `warning` or `notice`. Severity weighs on the health score (see [User guide → Scores](user-guide.md#scores)).
- **Theme**: `crawlability`, `https`, `linking`, `on-page`, `international`, `markup` or `other`. Each theme gets its own score. The `markup` theme only has check 45 so far.
- **Scope**: a *page* check examines each page it applies to, and its `examined` count is the number of those pages. A *site* check examines the site as a whole, so its `examined` is 1.

The ids follow the numbering used by Semrush's Site Audit, so that results can be compared. zero-audit is an independent project, not affiliated with or endorsed by Semrush, and the check wording is original. Ids **1000–1999** are reserved for our own checks. The CLI and the dashboard show the labels in French.

Thresholds live in `src/domain/thresholds.ts`, and the checks themselves in `src/domain/checks/`.

| Id | Severity | Theme | Scope | What it flags | How to fix |
|---:|---|---|---|---|---|
| 1 | error | crawlability | page | A page answers with a 5xx status. | Fix the server error, and check the logs and upstreams. |
| 2 | error | crawlability | page | A page answers with a 4xx status. | Restore the page, redirect it (301), or remove the links to it. |
| 3 | error | on-page | page | An HTML page has no `<title>`. | Add a unique, descriptive title. |
| 4 | notice | crawlability | page | An internal page is blocked from crawling by `robots.txt`. There is one occurrence per blocked URL. | Check that the block is intended; otherwise relax the matching `Disallow` rule. |
| 6 | error | on-page | page | Several pages share the same title. There is one occurrence per page involved. | Give each page its own title. |
| 7 | error | crawlability | page | Several pages have exactly the same HTML (same SHA-256 content hash) and do not all declare the same canonical. `info.duplicates` lists the other pages of the group. | Merge the pages, redirect them, or declare one canonical page. |
| 8 | error | linking | page | An internal link points to a page that failed (4xx, 5xx or network error). The occurrence is on the linking page. | Update or remove the link. |
| 9 | error | crawlability | page | A page did not answer within the crawler's time limit (`timeout`). | Look at the server's performance and load. |
| 11 | error | crawlability | page | A page could not be reached: connection, DNS, blocked or other network failure. `info.kind` gives the failure. | Check the host, DNS and firewall, then the URL itself. |
| 15 | error | on-page | page | Several pages share the same meta description. | Write a specific description for each page. |
| 20 | error | on-page | page | An HTML page answering 2xx has no `<meta name="viewport">`. | Add `<meta name="viewport" content="width=device-width, initial-scale=1">` to the head. |
| 21 | error | other | page | An HTML page answering 2xx weighs more than 2 MiB (2,097,152 bytes, UTF-8 size of the received document). `info.bytes` gives the size. | Trim the markup: remove inline data, split the page, paginate long lists. |
| 23 | error | international | page | An HTML page answering 2xx has a `<link rel="alternate" hreflang>` whose value is neither `x-default` nor a valid `language[-script][-region]` code (case ignored). `info.invalid` lists the invalid values. | Use a real language code, optionally with a region: `en-GB`, not `en-UK`; `fr-FR`, not `fr_FR`. |
| 24 | error | international | page | An HTML page answering 2xx has hreflang alternates that contradict each other: the same language (case ignored) points to two different URLs (`info.conflicts`, fragments ignored), or no alternate points to the page itself or to its canonical (`missing-self-reference`). `info.reasons` lists `conflict` and/or `missing-self-reference`. | Give each language a single URL and include the page itself in its hreflang set. |
| 25 | error | international | page | An HTML page answering 2xx has a `<link rel="alternate" hreflang>` pointing to a crawled page that answers 3xx, 4xx, 5xx or failed at network level. `info.targets` lists each `lang`, `url` and `status` (`null` for a network failure). | Point the hreflang to the final, 200-answering URL of the language version. |
| 26 | error | https | page | An HTML page answering 2xx is served over `http:` rather than `https:`. | Serve the page over HTTPS and redirect the http URL to it. |
| 30 | error | https | page | An HTML page answering 2xx served over `https:` loads resources over `http:` (mixed content): `img`/`source` (`src`, `srcset`), `script`, `link rel=stylesheet`, `iframe`, `video` (`src`, `poster`), `audio`, `embed`, `object`. `info.total` is the real count and `info.urls` the resolved URLs (capped at 20). | Load these resources over `https:`. |
| 31 | warning | https | page | A page on an https site has `<a>` links to internal URLs written with `http:`, including those that redirect to https. One occurrence per page; `info.targets` lists the target URLs, sorted. | Rewrite these links with `https:`. |
| 33 | error | crawlability | page | A redirecting URL goes through at least 2 redirects before reaching its destination, or leads into a loop. `info` gives the `chain` (the URLs followed in order, without the starting URL) and `loop`, plus `truncated` when the 10-hop cap was reached. | Redirect straight to the final destination and update the links. |
| 38 | error | crawlability | page | A page declares a canonical URL that points to a crawled page answering 4xx, 5xx or failing at network level. `info` gives the `canonical` and the `status` (`null` for a network failure). | Point the canonical to a page that answers 200, or remove it. |
| 39 | error | crawlability | page | An HTML page answering 2xx declares two or more `<link rel="canonical">`, even identical ones. `info.urls` lists their URLs in document order (capped at 20). | Keep a single canonical per page. |
| 40 | error | crawlability | page | An HTML page answering 2xx redirects with `<meta http-equiv="refresh">` to a target URL. `info.delaySeconds` and `info.target` give the delay and the destination. The target is not queued for crawling. | Use a server-side redirect (301) instead. |
| 44 | error | linking | page | An HTML page answering 2xx has `<a>` links whose href is broken: it cannot be parsed as a URL, its scheme is outside the closed list (http, https, mailto, tel, sms, ftp, javascript, data), or it is a malformed `http` (`http:/x`, `https//x`). `#`, empty and `javascript:void(0)` are ignored. One occurrence per page; `info.total` is the real count and `info.examples` the raw hrefs (capped at 20). | Fix or remove these links. |
| 45 | error | markup | page | An HTML page answering 2xx has at least one invalid JSON-LD block (`<script type="application/ld+json">`). A block is valid when it parses as JSON, has an `@context` at its root, and every top-level node (object, array item or `@graph` item) has an `@type`. `info.invalid` gives the number of invalid blocks and `info.reasons` their reasons (`unparseable`, `missing-context`, `missing-type`). One occurrence per page. schema.org vocabulary, microdata and RDFa are not validated. | Fix the JSON syntax, add `@context` and `@type`. |
| 46 | error | on-page | page | An HTML page answering 2xx has a viewport meta tag whose content sets no `width` (an empty content counts). `min-width` is not a width. | Set `width=device-width` in the viewport content. |
| 101 | warning | on-page | page | The title is shorter than 30 characters. | Make the title more descriptive. |
| 102 | warning | on-page | page | The title is longer than 60 characters. | Shorten it so it is not truncated in search results. |
| 103 | warning | on-page | page | An HTML page has no `<h1>`. | Add one main heading. |
| 104 | notice | on-page | page | An HTML page has several `<h1>`. | Keep a single main heading. |
| 105 | warning | on-page | page | The `<h1>` is identical to the `<title>`, compared after normalising case and whitespace. | Make the heading complement the title instead of repeating it. |
| 106 | warning | on-page | page | An HTML page has no meta description. | Add a meta description. |
| 108 | warning | linking | page | A page has more than 3000 links. `info.count` gives the number of links. | Reduce the number of links: split the page or trim menus and lists. |
| 109 | warning | crawlability | page | A page answers with a temporary redirect (302, 303 or 307). `info` gives the `status` and the `target`. | Replace it with a permanent redirect (301 or 308) if the move is final, and update the links. |
| 110 | warning | on-page | page | An HTML page answering 2xx has `<img>` elements with no `alt` attribute. `info.total` is the real count and `info.examples` lists at most 20 `src` values. | Add a descriptive `alt` to each informative image, and `alt=""` to decorative ones. |
| 111 | error | other | page | An HTML page answering 2xx took more than 3000 ms to respond. `info.responseTimeMs` gives the time. | Investigate server time: caching, database queries, hosting. |
| 112 | warning | on-page | page | The text-to-HTML ratio is below 10 %. The ratio is the UTF-8 byte size of the visible body text divided by the byte size of the HTML. | Reduce markup bloat or add real content. |
| 113 | warning | crawlability | page | A URL has more than 2 query parameters. `info.count` gives the number of parameters. | Simplify the URL: keep only the parameters that change the content. |
| 114 | warning | international | page | An HTML page answering 2xx declares no language: no `lang` attribute on `<html>` and no `<link rel="alternate" hreflang>`. | Add `<html lang="...">` with the page language. |
| 115 | warning | on-page | page | An HTML page answering 2xx declares no encoding: no `charset` in the `Content-Type` header and no `<meta charset>` (or `http-equiv="Content-Type"` charset) in the document. | Declare `<meta charset="utf-8">` in the head, or send a charset in the `Content-Type` header. |
| 116 | warning | on-page | page | An HTML page answering 2xx does not start with a `<!DOCTYPE>` (comments and whitespace may come first), which leaves browsers in quirks mode. | Add `<!DOCTYPE html>` as the first line of the document. |
| 117 | warning | on-page | page | The page has fewer than 200 words of visible text. | Expand thin content, or merge or noindex the page. |
| 121 | warning | on-page | page | An HTML page answering 2xx is built with `<frameset>` or `<frame>`. An `<iframe>` alone is not reported. | Replace frames with a regular page layout so that each URL carries its full content. |
| 122 | warning | crawlability | page | The path of a URL contains an underscore. | Use hyphens to separate words in URLs. |
| 123 | warning | linking | page | A page has internal links with `rel="nofollow"`. There is one occurrence per page; `info.targets` lists the target URLs, sorted. The `rel` value is read as a list of tokens, case ignored (`noopener NoFollow` counts, `nofollowed` does not). | Check that the attribute is intended; otherwise remove it so link equity flows to your own pages. |
| 125 | warning | crawlability | site | No sitemap was found. | Publish a sitemap and declare it in robots.txt. |
| 129 | warning | other | page | An HTML page answering 2xx is served without a compression `content-encoding` (gzip, br, zstd or deflate; a list such as `gzip, identity` counts as compressed, `identity` alone does not). | Enable gzip or brotli on the web server. |
| 136 | warning | crawlability | page | A URL is 101 to 200 characters long. `info.length` gives the length. A URL of more than 200 characters is reported by 201 only. | Shorten the URL: drop unnecessary words, folders and parameters. |
| 137 | notice | other | site | There is no `llms.txt`: the file does not answer with a 2xx. | Publish an `llms.txt` that describes the site for AI agents. |
| 201 | notice | crawlability | page | A URL is more than 200 characters long. `info.length` gives the length. | Shorten the URL: drop unnecessary words, folders and parameters. |
| 202 | notice | linking | page | A page has external links with `rel="nofollow"`. One occurrence per page, with `info.targets` sorted, read like check 123. | Check that the attribute is intended for these third-party links. |
| 203 | notice | crawlability | site | There is no `robots.txt`. | Publish a robots.txt, even a permissive one. |
| 204 | notice | international | page | An HTML page answering 2xx has a hreflang whose primary language (`de` in `de-AT`, case ignored) differs from the `lang` of the crawled target page, an HTML 2xx page that declares one. `x-default` is ignored. `info.targets` lists `lang`, `url` and `targetLang`. | Align the hreflang with the language the target page declares, or fix the target's `lang` attribute. |
| 205 | notice | https | site | The home page is served over HTTPS without a `Strict-Transport-Security` header. | Enable HSTS on the web server. |
| 209 | notice | crawlability | page | A page is excluded from the index by an `X-Robots-Tag` HTTP header (`noindex` or `none`). `info.value` gives the header value. | Check that the exclusion is intended; otherwise remove the directive from the server configuration. |
| 212 | notice | crawlability | page | A page is more than 3 clicks away from the home page. `info.clicks` gives the number of clicks. | Link to it from pages closer to the home page. |
| 213 | notice | linking | page | A page receives internal links from exactly one other page. | Link to it from more pages (navigation, related content). |
| 214 | notice | crawlability | page | A page answers with a permanent redirect (301 or 308). `info` gives the `status` and the `target`. | Update internal links to point directly to the target. |
| 215 | notice | linking | page | A page has `<a>` links to files (PDF, images, archives, media, office documents, CSS/JS/JSON/XML) rather than pages. One occurrence per page; `info.targets` lists the target URLs, sorted. | Check that each file link is intended, and say in the anchor that it is a file. |
| 216 | notice | linking | page | A page has `<a>` links with no anchor text (empty or whitespace only). One occurrence per page; `info.targets` lists the target URLs, sorted. | Give each link a descriptive text. |
| 217 | notice | linking | page | A page has `<a>` links whose anchor is generic (e.g. "click here", "read more", "en savoir plus"). One occurrence per page; `info.targets` lists the target URLs, sorted. | Use anchor text that describes the target page. |
| 220 | notice | on-page | page | An HTML page answering 2xx has more than 10,000 words of visible text. `info.words` gives the count. | Split the content over several pages, or add sections and a table of contents. |
| 1000 | warning | crawlability | page | The same page is reachable at two URLs, with and without a trailing slash, or on `www.` and the apex domain. Both answer HTML 2xx and do not share a canonical URL. | Redirect one form to the other, or declare a common `<link rel="canonical">`. |

## Notes on some definitions

- **Pages examined.**
  - Most page checks apply to HTML pages answering 2xx.
  - Checks 1 and 2 apply to every page that got an HTTP response.
  - Check 4 always applies: its `examined` is the number of pages explored, and the occurrences come from the URLs the crawler skipped because of `robots.txt`.
  - Check 7 applies to HTML 2xx pages; error pages are never counted in a group. It detects exact duplicates only (identical raw HTML): near-duplicates are not found. A group whose pages all declare the same canonical (after removing the `#fragment`) is not reported. It can overlap with check 1000 (the same page under two URL forms), check 6 (same title) and check 15 (same meta description), which report the same pages from another angle.
  - Check 8 applies to every page that has internal links.
  - Checks 109 and 214 apply to every page that got an HTTP response. A page redirects when its status is 302, 303 or 307 (109) or 301 or 308 (214); a 304 is not a redirect. The page is reported where it redirects, not where it is linked.
  - Check 33 applies to every page that answers with a redirect. Each crawled URL whose own chain has at least 2 hops, or ends in a loop (including a page redirecting to itself), is reported: in X→A→B→C, X and A are reported and B is not. A chain is cut at 10 hops and marked `truncated`.
  - Check 209 applies to every page that got an HTTP response. The header value is split on commas; an agent prefix (`googlebot: noindex`) is dropped and case is ignored. `noindex` and `none` are reported; `nofollow` alone is not.
  - Check 38 applies to HTML 2xx pages that declare a canonical. The canonical is compared with the crawled URLs after removing its `#fragment`; a canonical to a page that was not crawled, to a redirect or to itself is not reported.
  - Check 212 applies to HTML 2xx pages. Depth is counted in clicks, by a breadth-first walk over the internal `<a>` links from the final root (the start URL after its redirects, which are not clicks); a redirecting link lands on its destination at the cost of one click. The crawl's own `depth` is not used. Pages that only the sitemap reveals, with no link leading to them, are not reported: their click depth is unknown.
  - Checks 9 and 11 always apply: their `examined` is the number of pages explored. A timeout goes to 9, every other network failure to 11. Check 8 also reports internal links to these pages, so the same failure can appear in both (on the linking page for 8, on the failed page for 9 and 11).
  - Checks 113 and 122 apply to every crawled page. Check 113 counts the entries of the query string, so a repeated key counts each time (`?a=1&a=2&b=3` has 3); the threshold is strictly more than 2. Check 122 looks at the path only, never at the query string.
  - Check 108 applies to HTML 2xx pages. It counts every `<a>` link, internal and external, duplicates included; resources (images, scripts, stylesheets) are not counted. The threshold is strictly more than 3000.
  - Checks 136 and 201 apply to every crawled page and measure the length of the stored URL, in characters (`url.length`). The thresholds are strictly more than 100 (136) and strictly more than 200 (201); 136 stops at 200, so a URL is never reported by both.
  - Checks 123 and 202 apply to HTML 2xx pages that have at least one internal (123) or external (202) `<a>` link; resources are ignored. They emit one occurrence per source page, with the sorted, de-duplicated targets in `info.targets`.
  - Check 216 applies to HTML 2xx pages that have at least one internal or external `<a>` link; resources are ignored. The anchor is the link text collected by the parser (`.text()`), so an image-only link such as a clickable logo has an empty anchor and is reported: this is a known false positive, because `alt` and `aria-label` are not read.
  - Check 215 applies to the same pages as 216. A link is reported when its path ends with an extension of a closed list (pdf, zip, rar, 7z, gz, jpg, jpeg, png, gif, webp, avif, svg, ico, mp3, mp4, webm, mov, doc, docx, xls, xlsx, ppt, pptx, css, js, json, xml), read on the URL path (query ignored, case ignored), or, for an internal target, when the crawl got a 2xx answer that is not HTML. External links are judged by extension only, since no request is made to them.
  - Check 217 applies to the same pages as 216. The anchor is compared for equality, not inclusion, with a closed list of 13 generic phrases (French and English), after lowercasing, collapsing spaces and removing trailing punctuation: "En savoir plus." is reported, "en savoir plus sur nos tarifs" is not. Empty anchors are left to 216.
  - Check 26 applies to HTML 2xx pages and reports each one whose URL starts with `http:`, whatever the scheme of the home page: a site served entirely over http has all its pages reported. An http URL that redirects (3xx) is not reported, since it does not serve content. As a consequence the `https` theme is now scored, and a crawl of an http-only site (including the local `http://127.0.0.1` fixtures) gets 0 for it.
  - Check 31 only applies when the final home page (after redirects) is `https:`; on an http site it examines nothing. It applies to HTML 2xx pages with at least one internal `<a>` link and reports internal links whose URL starts with `http:`, even when that URL redirects to https. External links are ignored.
  - Check 129 applies to HTML 2xx pages and reads the `content-encoding` response header. The crawler keeps the default `Accept-Encoding` of undici (gzip, deflate, and more), so a server that compresses only for browsers, or a CDN that negotiates differently, may be reported although real visitors get compressed pages.
  - Checks 20 and 46 apply to HTML 2xx pages whose HTML facts were recorded; pages from snapshots made before the facts existed are not examined. Check 20 reports a missing viewport tag, check 46 a tag without `width=` (read case-insensitively), so a page is never reported by both. Only the first viewport tag is read.
  - Check 115 applies to HTML 2xx pages whose HTML facts were recorded. A charset in the `Content-Type` header or in the document is enough. The crawler's decoder strips a leading byte order mark, so a page whose only declaration is a BOM is reported although browsers honour it.
  - Check 116 applies to HTML 2xx pages whose HTML facts were recorded, like check 115. It looks for a doctype at the start of the raw document only.
  - Check 110 applies to HTML 2xx pages whose HTML facts were recorded and reports only a missing `alt` attribute: an empty `alt=""` is legitimate for decorative images and is never reported.
  - Check 121 applies to the same pages and looks for `<frameset>` and `<frame>` (commented-out ones are ignored); `<iframe>` does not count.
  - Check 30 applies to https HTML 2xx pages whose HTML facts were recorded. Resources are read from the markup, resolved against `<base>`, and never requested. `<a>` links are not resources (check 31). A `Content-Security-Policy: upgrade-insecure-requests` header, which makes browsers upgrade these requests, is not taken into account.
  - Check 44 applies to HTML 2xx pages whose HTML facts were recorded; only `<a href>` values are examined (rule A3), and the other link checks are unchanged.
  - Checks 39 and 40 apply to HTML 2xx pages whose HTML facts were recorded. Check 40 ignores a refresh with no `url=` (a plain reload).
  - Check 23 applies to HTML 2xx pages that have at least one hreflang alternate (HTML only, not the `Link` header or sitemap). Codes are validated with the ICU data of Node: a known language, an optional known script and an optional two-letter region, with no variant or extension; deprecated codes such as `iw` are rejected. The language is not restricted to ISO 639-1. The current ISO 639-1 codes that ICU rewrites (`tl`, `tw`) are accepted; surrounding whitespace is not trimmed, so `" fr"` is reported.
  - Check 24 applies to the same pages as check 23 (HTML 2xx with at least one hreflang alternate) and reads the same HTML-only alternates. A self-reference is an alternate equal, after normalisation, to the page URL or to its declared canonical. Reciprocity with other pages is not checked.
  - Checks 25 and 204 only judge hreflang targets that the crawl already visited: a target outside the crawl (for instance beyond `--limit`, or on another host) is never queued nor reported (rule A5). Targets are matched on the normalised URL, fragment removed.
  - Check 114 applies to HTML 2xx pages whose HTML facts were recorded; either a non-empty `lang` or at least one hreflang alternate is enough.
  - Check 21 applies to HTML 2xx pages whose HTML facts were recorded; the size is the UTF-8 byte length of the document the crawler read (threshold `MAX_HTML_BYTES`, 2 MiB), strictly exceeded. Check 220 compares the visible word count to `TOO_MUCH_CONTENT_WORDS` (10,000 words), strictly exceeded.
  - Check 111 applies to HTML 2xx pages and compares the response time strictly to 3000 ms. It is the time seen by the crawler, from sending the request to reading the whole body, not a browser loading time: network distance and the crawler's own load can inflate it.
  - Only pages reached within the `--limit` are examined.
- **URL variants (1000).**
  - URLs are never merged: `/about` and `/about/` are distinct pages when both are linked.
  - After the crawl, zero-audit requests the other form (with or without the slash) of each HTML page, at most once per page. These requests honour robots.txt and the politeness delay.
  - It also requests the home page once on the alternate host (`www.` or apex).
  - These probes are stored with the audit but are not counted as crawled pages.
  - A shared canonical means search engines already treat both forms as one page, so nothing is reported.
- **Site files.** `robots.txt`, the sitemaps and `llms.txt` are requested and their HTTP status is stored with the audit. They are not counted as crawled pages.
- **Single incoming link (213).** Links from a page to itself are ignored.
- **HSTS (205).** Only the home page is examined.
